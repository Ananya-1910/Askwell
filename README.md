# AskWell

**Learn to use AI, one small step at a time.**

AskWell is a free web app that teaches complete beginners, of any age, how to use Claude and other AI tools clearly, carefully, and safely.

**Live site:** https://ananya-1910.github.io/askwell/

> Student project in testing. AskWell is independent and is not made by, or officially connected to, Anthropic, Claude, or any tool listed in it.

## Features

- **7 short lessons** with examples, practice, and a quiz at the end of each one, including a lesson on spotting AI scams
- **Practice box** that checks a request for four ingredients (what, background, shape, tone) as you type
- **5 languages:** English, Hindi, Telugu, Spanish, and Arabic, with full right-to-left layout for Arabic
- **Read-aloud lessons** using the device's text-to-speech
- **Country picker** that adapts examples and tool availability
- **Tool finder** that recommends 3 tools from 3 quick questions
- **Directory of 66 AI tools** with what each is for, where it runs, and how to start
- **20 prompt templates** for students, job seekers, shop owners, teachers, and everyday life
- **Certificate guide** covering free and paid AI certifications from Anthropic, Google, Microsoft, IBM, and AWS
- **AskWell completion certificate** generated in the browser
- **Accessibility:** text-size control, skip link, keyboard support, screen-reader labels, and dark mode

## How it works

AskWell is a single HTML file with no build step and no server. Progress and profiles are saved in the learner's own browser.

When opened inside Claude, extra features turn on: live coaching from Claude, sign-in with a Claude account, progress sync, and anonymous feedback. On the public site, those features are hidden and everything else works.
